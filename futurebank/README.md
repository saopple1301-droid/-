# FutureBank

努力をお金に換算して「未来の自分への預金」として貯めていく、学生向けの努力習慣化アプリ（プロトタイプ）。

| 項目 | 内容 |
|---|---|
| ターゲット | 学生 |
| ジョブ | 努力を習慣化したい |
| 現状の対策 | Studyplus |
| 価値・差別化 | 努力をお金に換算することで動機づける |

## 機能
- **努力の記録（入金）**: 日付・科目・時間・集中度・メモを記録。`時間 × 努力の時給 × 集中度` が残高に入金される
- **預金残高ダッシュボード**: 残高・累計時間・連続記録日数・今週の入金額
- **目標とのギャップ**: 目標（時間・期限・科目）を設定すると、
  - 進捗率と、今日時点の理想ペースに対して何時間先行／遅れているか（金額換算つき）
  - 期限までに必要な1日あたりの学習時間
- **直近7日のグラフ**、入金履歴
- **努力の時給**の設定

## 使い方
`index.html` をブラウザで開くだけ。データはブラウザの localStorage に保存されます（サーバー不要）。
